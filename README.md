# М'ята & Еспресо — як редагувати сайт

Це статичний сайт без збірки: відкрийте папку у VS Code, запустіть **Live Server**
(або просто відкрийте `index.html` у браузері) — і все працює.

**Жива версія:** https://stas-yeyeg.github.io/myata-espresso/

## Що змінилося

- **Головна** перетворена на динамічну журнальну сторінку: hero-карусель, бігунок,
  категорії-настрої, горизонтальні хіти, рулетка випадкового рецепта, живий пошук
  по інгредієнтах, бенто-блок про кухню та підписка з конфеті.
- **Каталог** отримав пошук, фільтри, сортування, «показати ще» і URL-параметри
  (`?category=dessert`, `?q=шоколад`, `?recipe=27`).
- **Довідник** перезібраний у картки правил, адаптивну таблицю замін, FAQ-акордеон
  і форму зворотного зв'язку.
- Додано **нічну тему**, мобільне меню, прогрес скролу, reveal-анімації та
  оптимізовані WebP-зображення.

## Де що лежить

```
myata-espresso/
├─ index.html          головна
├─ recipes.html        каталог
├─ tips.html           довідник
├─ css/
│  ├─ style.css        спільна дизайн-система, каталог, довідник, футер
│  └─ home.css         стилі тільки головної (hero, рулетка, пошук, бенто)
├─ js/
│  ├─ db.js            35 рецептів (дані)
│  ├─ main.js          теми, меню, модалка, каталог, FAQ, форми
│  └─ home.js          hero-карусель, хіти, рулетка, живий пошук, конфеті
└─ images/
   ├─ *.jpg            оригінальні фото
   ├─ thumbs/*.webp    картки 720×900
   └─ large/*.webp     великі фото 1200×1500 для hero та модалки
```

## Кольори та шрифти

Усе — у `css/style.css`, блок `:root` на початку файлу:

```css
--paper: #f6efdf;   /* фон */
--ink: #17120d;     /* основний текст */
--mint: #a9f5c9;    /* м'ята */
--lime: #dfff57;    /* акцент */
--tomato: #ff5c39;  /* другий акцент */
```

Нічна тема — блок `[data-theme="dark"]` одразу під ним.

Шрифти підключені з Google Fonts у `<head>` кожної сторінки:
**Unbounded** (заголовки), **Manrope** (текст), **Caveat** (рукописні акценти).
Якщо інтернету немає, браузер покаже системні запасні шрифти.

## Рецепти

Усі 35 рецептів — у `js/db.js`. Формат одного запису:

```js
{
  id: 36,
  title: "Назва страви",
  category: "main",              // soup | main | salad | breakfast | dessert | bakery | drink
  categoryName: "Основні страви",
  time: "30 хв",
  difficulty: "Легка",
  calories: "420 ккал",
  servings: "2 порції",
  image: "images/my-dish.jpg",
  description: "Короткий опис.",
  ingredients: ["Інгредієнт — 100 г"],
  steps: ["Перший крок.", "Другий крок."],
  chefTip: "Порада від шефа."
}
```

Після додавання рецепта картки на головній і в каталозі з'являться автоматично.
Лічильники в тексті (`35 рецептів`) — статичні, їх варто оновити вручну в HTML.

Для нового фото покладіть оригінал у `images/`. Якщо не хочете робити WebP-версії,
сайт усе одно працюватиме: картка автоматично підвантажить оригінал, якщо стисненої
версії немає. Але для швидкості краще додати файли в `images/thumbs` і `images/large`.

## Hero-карусель

Щоб змінити добірку на головній, відкрийте `js/home.js` і знайдіть:

```js
const heroIds = [1, 4, 27, 17, 7];
```

Це `id` рецептів із `db.js`, які показуються у великій картці. Порядок — це порядок
слайдів. Далі можна змінити `shortTitles` (короткі підписи) і швидкість автозміни
(зараз 5200 мс).

## Форми

Форми на сторінці довідника й підписка — **демо-версії**: вони валідують поля,
показують повідомлення та конфеті, але нікуди не надсилають дані. Щоб отримувати
реальні листи, підключіть, наприклад, [Formspree](https://formspree.io/) або власний
бекенд у `js/main.js` (блок `feedbackForm`) і `js/home.js` (блок `subscribeForm`).

## Перевірено

Сайт протестований у Chrome на ширинах 320, 390, 768, 1024, 1440 px:
немає горизонтального скролу, помилок у консолі чи битих посилань.
